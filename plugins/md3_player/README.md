# Material Player (md3_player)

Стилизация встроенного музыкального плеера Telegram в стиль Material Expressive (Material You) для **exteraGram**.

📥 **Скачать плагин:** в посте со всеми плагинами [t.me/RnPlugins/38](https://t.me/RnPlugins/38)

---

## Возможности

- **Material You**: цвета плеера подстраиваются под обложку трека или тему Telegram на выбор
- **Волнистый прогресс**: анимация волны на полосе перемотки (можно выключить в настройках)
- **Плавающий мини-плеер**: удобная карточка в списке чатов с плавным открытием плеера
- **Панель в чате**: компактный плеер сверху в переписке
- **Синхронизированные тексты песен**: автоматический поиск и показ слов (LRCLIB)
- **Очередь воспроизведения**: список треков с сохранением порядка из профиля
- **Скорость воспроизведения**: переключение скорости трека без сброса при переключении

---

## Установка

1. Скачайте `.plugin` файл из [поста со списком плагинов](https://t.me/RnPlugins/38).
2. Нажмите на файл прямо в чате и подтвердите установку в появившемся окне.
